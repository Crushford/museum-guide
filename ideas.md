# Museum Guide – Ideas Backlog

This file captures conceptual ideas, strategic directions, and future possibilities.  
Items here are not committed roadmap features.

## Core Philosophy

- Structured museum knowledge layer
- Wikipedia-aligned canonical context
- LLM-connected conversational layer
- Audio-first exploration experience
- Community-driven improvement over time

- Museum dashboard with moderation tools
